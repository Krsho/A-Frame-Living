# Images

Put your own photos here using the file names below. Until a file exists, the website shows a "Photo coming soon" placeholder in its place, so nothing breaks.

Only use photos you own or have permission to use. Do not use stock photos presented as your own completed projects.

| File | Used on |
|---|---|
| `hero.jpg` | Home page, large image at the top |
| `about.jpg` | Home page, "About A-Frame Living" section |
| `atlantic/main.jpg` | Atlantic card and detail page (main image) |
| `atlantic/gallery-1.jpg`, `atlantic/gallery-2.jpg` | Atlantic detail page gallery |
| `norway/main.jpg`, `norway/gallery-1.jpg`, `norway/gallery-2.jpg` | Norway |
| `scandinavia/main.jpg`, `scandinavia/gallery-1.jpg`, `scandinavia/gallery-2.jpg` | Scandinavia |
| `continental/main.jpg`, `continental/gallery-1.jpg`, `continental/gallery-2.jpg` | Continental |

Tips:
- Landscape photos work best (about 4:3). Around 1600 px wide is enough.
- Compress photos before adding them (for example with squoosh.app) so the site stays fast.
- To add more gallery photos, add file names to the `images` list in `frontend/js/data/houses.js`.
